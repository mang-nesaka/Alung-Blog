# Alung-Blog 🚀

Blog pribadi interaktif karya **Alunggu Simatupang** — Mahasiswa Teknik Informatika Universitas Bandung. Berisi cerita perjalanan hidup, ketertarikan terhadap dunia IT, programming, hingga perkembangan Artificial Intelligence (AI).

## ✨ Fitur Blog
- 🌓 **Dark & Light Mode Toggle** (disimpan via local storage)
- 📊 **Dynamic Reading Progress Bar** di bagian atas halaman
- ⏱️ **Kalkulator Estimasi Waktu Baca** otomatis
- 👏 **Interaksi Reaksi Pembaca** (Inspiratif, Semangat, Keren, Mantap)
- 🔗 **Fitur Bagikan / Salin Tautan** dengan Toast notification
- 📱 **Desain Responsif & Modern** dengan tipografi Plus Jakarta Sans dan Glassmorphism UI

## 🌐 Menjalankan via GitHub Pages
1. Masuk ke repository GitHub ini: `Settings` > `Pages`.
2. Di bagian **Build and deployment** > **Branch**, pilih `main` dan folder `/(root)`.
3. Klik **Save**.
4. Website blog Anda akan langsung live di:
   `https://mang-nesaka.github.io/Alung-Blog/`
